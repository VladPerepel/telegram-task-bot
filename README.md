# 🎵 MusicFlow Bot

> Быстрый и удобный Telegram-бот для поиска и скачивания любой музыки прямо в чат на базе **Python 3**, **aiogram 3**, **yt-dlp** и **ffmpeg**.

![Python](https://img.shields.io/badge/python-3.9+-blue.svg)
![aiogram](https://img.shields.io/badge/aiogram-3.x-brightgreen.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

---

## ✨ Возможности

* 🔎 **Умный поиск треков:** просто напиши в чат имя любого исполнителя или название песни.
* 🎧 **Нативный плеер Telegram:** бот присылает треки в формате MP3 с указанием названия, автора и длительности.
* ⚡️ **Быстрая загрузка:** конвертация и отправка аудио за считанные секунды через `ffmpeg`.
* 🔥 **Быстрые кнопки:** подборки популярных треков и случайных хитов.
* 🧹 **Автоочистка:** бот не засоряет диск и сразу удаляет временные аудиофайлы после отправки.

---

## 🛠 Стек технологий

* **Язык:** Python 3.9+
* **Фреймворк:** [aiogram 3.x](https://docs.aiogram.dev/)
* **Поиск и обработка аудио:** `yt-dlp`, `static-ffmpeg`
* **Конфигурация:** `python-dotenv`

## 📁 Структура проекта

```text
telegram-task-bot/
├── main.py              # Точка входа и запуск polling
├── handlers.py          # Обработка поиска и отправки музыки
├── keyboards.py         # Меню и кнопки с результатами поиска
├── music_service.py     # Модуль поиска и загрузки MP3
├── config.py            # Конфигурация и токен бота
├── requirements.txt     # Зависимости
├── .env                 # Токен бота (в .gitignore)
└── README.md            # Документация
```

---

## 🚀 Запуск бота

```bash
# Активация окружения
source .venv/bin/activate

# Запуск
python3 main.py
```

После запуска напиши боту в Telegram название любимой песни! 🎉
