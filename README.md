# 📋 TaskFlow Bot

> Современный, быстрый и удобный Telegram-бот для управления задачами, целями и личной продуктивностью на базе **Python 3**, **aiogram 3** и **SQLite**.

![Python](https://img.shields.io/badge/python-3.9+-blue.svg)
![aiogram](https://img.shields.io/badge/aiogram-3.x-brightgreen.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

---

## ✨ Возможности

* 📋 **Интерактивный список дел:** быстрый просмотр всех актуальных задач.
* ⚡️ **Inline-управление:** завершение (`done`) и удаление (`delete`) задач в один клик без лишнего спама в чате.
* ➕ **Машина состояний (FSM):** комфортное пошаговое добавление задач с кнопкой отмены в любой момент.
* 📊 **Статистика продуктивности:** наглядный визуальный прогресс-бар и процент выполнения задач.
* 📜 **История выполненного:** архив последних закрытых дел.
* 💾 **Локальная база данных SQLite:** легковесное, надёжное хранилище без необходимости поднимать внешние серверы БД.

---

## 🛠 Стек технологий

* **Язык:** Python 3.9+
* **Фреймворк:** [aiogram 3.x](https://docs.aiogram.dev/) (асинхронный фреймворк для Telegram Bot API)
* **База данных:** SQLite 3
* **Конфигурация:** `python-dotenv`

## 🚀 Быстрый старт

### 1. Получение токена бота
1. Открой Telegram и найди официального бота [@BotFather](https://t.me/BotFather).
2. Отправь команду `/newbot` и следуй инструкциям (придумай имя и username).
3. Скопируй полученный `HTTP API Token`.

### 2. Клонирование и переход в директорию
```bash
git clone <URL_РЕПОЗИТОРИЯ>
cd telegram-task-bot
```

### 3. Настройка виртуального окружения
```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 5. Настройка переменных окружения
Создай файл `.env` на основе примера:
```bash
cp .env.example .env
```
Открой `.env` и вставь токен твоего бота:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
```

### 6. Запуск бота
```bash
python3 main.py
```

После этого перейди в своего бота в Telegram и нажми **/start**! 🎉
